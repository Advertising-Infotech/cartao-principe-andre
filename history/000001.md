### O que é o projeto
Cartão de visitas digital multilíngue para o Príncipe André Luís, hospedado no GitHub Pages. Exibe um carrossel com 55+ títulos, honrarias, certificações e diplomas recebidos de diversas organizações ao redor do mundo.

### O arquivo `atualizar_carrossel.py`
Script de atualização incremental do carrossel que:
1. Lê o `Titulos.xlsx` — fonte mestra com sequência e textos em português (colunas A-E: filename, badge, title, desc, tag)
2. Detecta mudanças — compara o XLS com os 7 arquivos JSON de tradução (`Titulos_pt.json`, `Titulos_en.json`, etc.), identificando itens novos e alterados
3. Insere placeholders nos JSONs de idiomas sem tradução (marcados com `[PT]`)
4. Atualiza os 7 HTMLs — injeta o `carouselData` (array JavaScript) em cada `index-*.html`
5. Atualiza o contador `1 / N` em cada página
6. Corrige um bug no elemento `imgEl` do carrossel (`fix_img_el`)
