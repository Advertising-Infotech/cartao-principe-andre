### 2. Reescrita completa do `atualizar_carrossel.py` (v2.0)

**Problema identificado no script anterior:**
- Inseria placeholders `[PT]` nos JSONs quando detectava itens novos
- Exigia tradução manual dos 6 idiomas por parte do usuário
- Não fazia reordenação automática nos JSONs
- Não traduzia automaticamente

**Solução implementada (v2.0):**
- Remoção total do prefixo `[PT]` — itens novos entram com texto direto
- Tradução automática para os 6 idiomas via `deep-translator` (GoogleTranslator)
- Cache de traduções para evitar chamadas repetidas à API
- Reordenação automática dos JSONs conforme a ordem do Excel
- Atualização automática dos 7 HTMLs com os textos traduzidos
- Rate limit de 0.3s entre traduções para respeitar limites da API
- Tratamento de erros com fallback para texto original em caso de falha

### 3. Fluxo de trabalho resultante

**Antes (script v1.0):**
1. Editar Excel → rodar script → script insere `[PT]` nos JSONs
2. Editar manualmente 7 JSONs para traduzir
3. Rodar script novamente para atualizar HTMLs

**Depois (script v2.0):**
1. Editar Excel → rodar script → script traduz e atualiza TUDO automaticamente

### 6. Estrutura do novo script

```
atualizar_carrossel.py
├── translate_text()        → traduz texto via GoogleTranslator com cache
├── translate_item()        → traduz badge/title/desc/tag de um item
├── load_xls()              → lê Titulos.xlsx
├── load_json()             → lê JSON existente como dict {filename: dados}
├── save_json()             → salva JSON na ordem do Excel
├── generate_carousel_item() → gera linha JS para carouselData
├── update_html()           → substitui carouselData + counter no HTML
└── main()                  → orquestra tudo
```

### 7. Dependências

- `deep-translator` (tradução automática via Google Translate)
