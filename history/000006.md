### 3. Bug encontrado: códigos de idioma incorretos
**Problema:** `deep-translator` (GoogleTranslator) usa códigos diferentes:
- Hebrew: `iw` (não `he`)
- Chinese: `zh-CN` (não `zh`)

**Correção aplicada no script:**
```python
# Antes (errado):
"he": {"gt": "he"}
"zh": {"gt": "zh"}

# Depois (corrigido):
"he": {"gt": "iw"}
"zh": {"gt": "zh-CN"}
```
